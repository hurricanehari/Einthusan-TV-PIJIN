# Elil TV — Brought by PIJIN v0.7 · Personal Cinema

A native Android/Fire TV app based on the proven v0.6 catalogue and player. Independent personal project. Not an official Einthusan product.

## New in v0.7

- Continue Watching, with a prominent home row, one-click resume, and visible progress bars on movie posters.
- Resume Playback requests a fresh authorised playback URL, then seeks to the locally saved position. No expired streaming URL is stored.
- Saves playback position approximately every 10 seconds, on pause, on app background/stop, and when a film ends.
- My List / watchlist, available from film details, long-press quick menus, home rows and the sidebar.
- Recently Watched history, including completed movies.
- Remove from Continue Watching without removing My List or Recently Watched data.
- Restart Movie / Play from Beginning from film details and the long-press quick menu.
- Retains Recently Added and the other v0.6 native catalogue collections.
- Up to six device-local household profiles, each with separate history, progress and My List.
- **One shared first-party Einthusan sign-in for all local profiles.** Profile switching doesn't sign out or duplicate accounts. Account membership and any simultaneous-streaming restrictions are set by Einthusan, not Elil TV.

## Security and storage

Profiles and watch activity are stored in app-private Android SharedPreferences on THIS Firestick only. No cloud sync, password sync, account tokens or streaming URLs are stored in the local viewing data. These profiles are convenience profiles; they do **not** implement PINs, parental controls or isolation from other people with access to this Firestick. The existing native Einthusan login is shared across profiles.

Progress is marked complete at ~95% or when the player reports an ended stream; completed films leave Continue Watching but remain in Recently Watched. Films only appear in Continue Watching after 30 seconds of playback.

**Debug APK caution:** GitHub-hosted builds may be signed with a different autogenerated debug keystore on each run. If Android forces you to uninstall the prior APK to install the next version, ALL app data (including viewing history and stored sessions) may be erased. Before relying on progress long-term, configure a stable signing identity stored securely in GitHub Actions secrets; never commit a keystore or credentials to the public repository. This project does not yet export profiles or sync data.

## Build

1. Extract this archive and upload the complete `ElilTV-PIJIN-v07` folder to the root of `hurricanehari/Einthusan-TV-PIJIN`, next to v0.6. Leave earlier versions untouched.
2. Create `.github/workflows/build-v07.yml` using the **complete** `build-v07.yml` included in the project (also available as a separate download).
3. Commit, open GitHub Actions, select **Build Elil TV v0.7 APK**, and download the `Elil-TV-PIJIN-v0.7-APK` artifact.
4. Extract `app-debug.apk`; install on Fire TV Stick. It should retain the same application ID as v0.6.

## Device smoke tests

- Add a household profile and switch between it and Primary; verify My List/history is separate.
- Play a movie for 2 minutes, leave playback, then return to Home. Confirm Continue Watching and a progress bar.
- Select the Continue Watching tile and verify it resumes at the saved timestamp.
- From details, select Restart and verify playback starts at 0.
- Save a film to My List, restart the Firestick, check that the list is still there.
- Remove a movie from Continue Watching, ensure it still appears under Recently Watched.
- Watch to the end; confirm removal from Continue Watching and retention in Recently Watched.
- Test language-specific Recently Added, HD/Ultra HD entitlement (where available), regular login and site fallback.

## Limits

Live Firestick testing is still required. This project has not been compiled on a Firestick. Streams without a known duration may have no percentage bar until the duration is available. The app cannot grant or guarantee premium/Ultra HD access beyond a member's existing rights. No session or profile sync across devices.
