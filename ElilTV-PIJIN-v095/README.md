# Elil TV — Brought by PIJIN v0.9.5

Premium Fire TV UI polish based on v0.9.4.

- Compact cinematic hero, subtler gold/navy controls, denser film rows.
- Less catalogue chrome: single Filters entry, Search entry, no debug loading counts.
- Narrower navy hidden drawer with bottom-fixed profile and sign-in status.
- Minimal playback overlay: title, progress timeline, time labels and optional trick-play speed only.
- Fire TV OK pauses + shows progress; OK resumes + auto-hides after ~1 second.
- Physical Play/Pause operates directly and does not show the overlay.
- Left/Right taps seek 10s; holding scrubs; FF/RW buttons cycle 2x/4x/8x.
- Existing household data, logged-in session, catalogue and signing setup retained.

GitHub Actions signed release tag: `v0.9.5`, attached APK name: `Elil-TV.apk`.

This source archive must be built and tested on Fire TV before publishing as a stable release.
