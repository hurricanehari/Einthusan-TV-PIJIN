# Einthusan TV — Fire TV test prototype

**Status: prototype source, not a tested or ready-to-install APK.**

An unofficial Android TV launcher that loads `https://einthusan.tv/` in an Android WebView. This is **not** a Kodi-port, does **not** use the EinTamil Python code, and does **not** guarantee film playback. Fire OS WebView's remote navigation and video playback might fail or require revisions. Use the original Kodi add-on if you need dependable playback today.

## Build the debug APK without a local Android SDK

1. Create a new GitHub repository and upload the contents of this folder, including the hidden `.github` folder.
2. Open the repository's **Actions** tab and run **Build test Fire TV APK** (or push to `main`).
3. Download the `EinthusanTV-test-apk` workflow artifact, unzip it, and take `app-debug.apk`.
4. Install this debug build on your own Fire OS 7/8 device using ADB or Downloader after hosting the APK at a direct HTTPS download URL. A Downloader numeric code requires a separate URL-shortener step and is **not** generated by this project.

For local builds: Android Studio / JDK 17, Android SDK 35, Gradle 8.9; run `gradle assembleDebug`.

## Test list

- Launcher icon appears in **Your Apps & Channels**.
- Fire remote DPAD controls site links/buttons.
- Login remains in the site's own page (do not enter credentials into a third-party lookalike).
- Navigate to a film, try playback, fullscreen, pause/seek, exit fullscreen.
- If browsing or playback fails, capture the device model, Fire OS version, and whether audio/video plays.

## Scope & caveats

This test is only a website wrapper. It does not extract streaming endpoints, bypass access controls or ads, reproduce third-party interfaces, nor contain copyrighted movies. This project isn't endorsed by Einthusan or EinTamil. Site terms and media rights apply. Publishing/distributing an app using their brand may require permission. The test APK is unsigned for public release; debug signing is suitable only for private testing.
